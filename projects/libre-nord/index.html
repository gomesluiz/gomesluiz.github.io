Installation Instructions

  1. 1

    Download your preferred variant using the download buttons above.

  2. 2

    Open LibreOffice (any module such as Writer or Calc).

  3. 3

    In the top menu, go to Tools > Extension Manager...

  4. 4

    Click the Add button, browse to your downloads folder, select the downloaded .oxt file, and confirm.

  5. 5

    Restart LibreOffice completely so the palette and style files are properly loaded into the application cache.
